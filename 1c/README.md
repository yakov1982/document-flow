# 1С:Предприятие 8.3 — шаблон проекта в Git

Этот каталог предназначен для ведения проекта 1С:Предприятие 8.3 в Git в виде **текстовых исходников** (выгрузка конфигурации/расширения/обработок в файлы), а не в виде бинарных `*.cf/*.cfe/*.epf/*.erf`.

## Рекомендуемая структура

```
1c/
  src/        # исходники (выгрузка в файлы)
  tools/      # скрипты/подсказки (опционально)
```

## Как хранить исходники 1С в Git (варианты)

### Вариант A: 1C:EDT (Development Tools)
1. Создайте проект в EDT.
2. Убедитесь, что в репозиторий попадают **файлы проекта** и `src/`, а не workspace-мусор (например, `.metadata`).
3. Размещайте содержимое проекта внутри `1c/` (например, `1c/src/...`).

### Вариант B: Конфигуратор (выгрузка/загрузка в файлы)
Используйте стандартные ключи Конфигуратора:
- **Выгрузка** конфигурации в файлы (обычно: `/DumpConfigToFiles`).
- **Загрузка** из файлов (обычно: `/LoadConfigFromFiles`).

Рекомендуемая цель выгрузки: `1c/src/` (см. `1c/src/README.md`).

> Команды и ключи могут отличаться в зависимости от платформы/режима подключения (файловая/серверная ИБ). Если скажете ваш сценарий (EDT или Конфигуратор, файловая или серверная база) — добавлю готовые команды под ваш случай.

## Что дальше от вас нужно (чтобы сделать “проект” не только шаблоном)
Уточните, пожалуйста, **какой тип артефакта** вы хотите:
1) конфигурация (`*.cf`)  
2) расширение (`*.cfe`)  
3) внешняя обработка/отчёт (`*.epf/*.erf`)

и **как вы планируете работать**: через EDT или через Конфигуратор (выгрузка/загрузка в файлы).
