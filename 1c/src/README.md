# `1c/src/` — исходники 1С в виде файлов

Сюда складываются **текстовые исходники**, полученные выгрузкой из Конфигуратора или созданные/обновлённые в 1C:EDT.

## Общая идея

- В Git храним **только** то, что можно стабильно диффать и мерджить (XML/BSL и т.п.).
- Бинарные файлы (`*.cf/*.cfe/*.epf/*.erf/*.dt`) обычно **не коммитятся** — они собираются/выгружаются при необходимости.

Если вы скажете ваш формат (EDT-проект или выгрузка Конфигуратора), я добавлю сюда пример структуры и минимальный “скелет” метаданных.
