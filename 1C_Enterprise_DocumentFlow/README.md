# Документооборот — конфигурация 1С:Предприятие 8.3

Полноценная конфигурация для платформы **1С:Предприятие 8.3**, реализующая систему электронного документооборота (СЭД). Проект создан в формате выгрузки конфигуратора (XML) и предназначен для загрузки через Конфигуратор 1С или 1C:EDT.

## Функциональность

### Справочники
| Объект | Назначение |
|--------|-----------|
| **ВидыДокументов** | Классификатор видов документов (приказ, письмо, служебная записка и т.д.) |
| **Контрагенты** | Организации-корреспонденты (отправители/получатели) |
| **Сотрудники** | Сотрудники организации, участники согласования |
| **ШаблоныМаршрутов** | Шаблоны маршрутов согласования (цепочки этапов) |

### Документы
| Объект | Назначение |
|--------|-----------|
| **ВходящийДокумент** | Регистрация входящей корреспонденции |
| **ИсходящийДокумент** | Подготовка и отправка исходящих документов |
| **ВнутреннийДокумент** | Внутренние документы (приказы, распоряжения, служебные записки) |

### Перечисления
| Объект | Значения |
|--------|---------|
| **СтатусыДокументов** | Черновик, НаРегистрации, Зарегистрирован, НаСогласовании, Согласован, Отклонен, НаДоработке, Архив |
| **РезультатыСогласования** | Согласовано, ОтклоненоСЗамечаниями, НаДоработку |
| **РолиПользователей** | Администратор, Делопроизводитель, Согласующий, Исполнитель, Руководитель |

### Регистры сведений
| Объект | Назначение |
|--------|-----------|
| **ЖурналСогласования** | История согласования документов (кто, когда, результат, комментарий) |
| **ВерсииФайлов** | Версионирование прикреплённых файлов |
| **ЖурналАудита** | Полный аудит действий (создание, изменение, просмотр, печать) |

### Обработки
| Объект | Назначение |
|--------|-----------|
| **ПанельЗадач** | Рабочее место пользователя: мои задачи на согласование, просроченные, требующие внимания |

### Общие модули
| Модуль | Назначение |
|--------|-----------|
| **ДокументооборотСервер** | Серверная бизнес-логика: запуск согласования, проведение, нумерация |
| **ДокументооборотКлиентСервер** | Общие функции для клиента и сервера: валидация, формирование описания |
| **ОбщегоНазначения** | Утилиты общего назначения |

### Роли
| Роль | Описание |
|------|---------|
| **Администратор** | Полные права на все объекты |
| **Согласующий** | Чтение документов, запись в журнал согласования, работа с задачами |
| **Автор** | Создание и редактирование своих документов, просмотр статуса |


## Загрузка в 1С:Предприятие 8.3

### Через Конфигуратор

1. Создайте пустую информационную базу 1С:Предприятие 8.3
2. Откройте Конфигуратор
3. Меню **Конфигурация → Загрузить конфигурацию из файлов…**
4. Укажите путь к папке `Configuration/`
5. Нажмите **Загрузить**
6. Обновите конфигурацию базы данных (F7)

### Через 1C:EDT

1. Импортируйте проект: **File → Import → 1C:Configuration files**
2. Укажите путь к папке `Configuration/`
3. Выполните синхронизацию с информационной базой

## Сценарии использования

### 1. Регистрация входящего документа
- Создать документ «Входящий документ»
- Заполнить реквизиты: отправитель, номер, дата, вид документа
- Прикрепить файл (скан)
- Провести → документ получает регистрационный номер

### 2. Согласование
- Выбрать маршрут согласования (шаблон или вручную)
- Нажать «Отправить на согласование»
- Каждый согласующий видит задачу в «Панели задач»
- Согласующий принимает решение: согласовать / отклонить / на доработку
- После прохождения всех этапов документ переходит в статус «Согласован»

### 3. Аудит
- Все действия записываются в Журнал аудита
- Доступна история согласования по каждому документу

## Требования

- **Платформа**: 1С:Предприятие 8.3.20+ (рекомендуется 8.3.24+)
- **Режим совместимости**: 8.3.20
- **Режим управления блокировками**: Управляемый
- **Модальность**: Без использования модальности

## Лицензия

Проект распространяется свободно для обучения и использования в качестве стартового шаблона СЭД на платформе 1С.
