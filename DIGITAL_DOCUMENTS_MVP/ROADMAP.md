## 2. Рекомендуемые доработки (по приоритету)

### Высокий приоритет (ближайшие итерации)

#### 2.1. Расширение маршрутов согласования

- **Параллельное согласование** — несколько согласующих на одном шаге; документ считается согласованным по шагу, когда все утвердили.
- **Сроки выполнения** — deadline для каждого шага, напоминания (email/в системе).
- **Делегирование** — согласующий может передать задачу другому пользователю.

#### 2.2. Расширение карточки документа

- **Произвольные атрибуты** — JSON или key-value для настраиваемых полей.
- **Дата документа** — отдельное поле от даты создания.
- **Связь с контрагентами** — поле «от кого» / «кому» для входящих/исходящих.

#### 2.3. Регистрация и нумерация

- **Журнал регистрации** — отдельный список с возможностью присвоения рег. номера.
- **Автонамерация** — правила по типам документов (например, «ВХ-2024-001»).
- **Контроль уникальности** — проверка (doc_type, reg_number) при регистрации (частично уже есть).

#### 2.4. Улучшение поиска

- **Фильтры** — по дате, автору, контрагенту, типу.
- **Сохранённые фильтры** — пользовательские наборы условий.
- **Экспорт списка** — CSV/Excel.

---

### Средний приоритет

#### 2.5. Шаблоны документов

- **Типы документов** — настраиваемые (входящий, исходящий, внутренний, приказ и т.п.).
- **Шаблоны** — ODT/DOCX с подстановкой полей.
- **Связки** — входящий → исходящий (ответ на письмо).

#### 2.6. Поручения и контроль

- **Поручения** — создание задач на основе документа с исполнителем и сроком.
- **Контроль исполнения** — статусы, продление срока, отчёт.

#### 2.7. Просмотр и OCR

- **Предпросмотр** — PDF/изображения в браузере (PDF.js, canvas).
- **OCR** — извлечение текста из сканов (Tesseract, облачные API).
- **Полнотекстовый поиск** — по содержимому (SQLite FTS, Elasticsearch).

#### 2.8. Уведомления

- **Email** — при назначении задачи, при согласовании/отклонении.
- **Внутренние уведомления** — колокольчик в UI.
- **Webhook** — для интеграций.

---

### Низкий приоритет / долгосрочно

#### 2.9. Интеграции

- **Почта** — импорт входящих, отправка исходящих.
- **1С** — обмен справочниками и документами.
- **Скан** — загрузка со сканера (TWAIN/SANE).

#### 2.10. Архив и номенклатура дел

- **Номенклатура дел** — иерархия папок/дел.
- **Срок хранения** — для видов документов.
- **Архивирование** — смена статуса, выгрузка в архив.

#### 2.11. Мультитенантность

- **Организации** — изоляция данных по tenant.
- **Роли на уровне организации** — разные права в разных организациях.

#### 2.12. Мобильность

- **Адаптивный UI** — уже частично через CSS.
- **PWA** — офлайн-режим для просмотра.
- **Отдельное мобильное приложение** — React Native / Flutter.

## 4. Технический долг

- **Миграции БД** — переход на Alembic для версионирования схемы.
- **Тесты** — unit/integration для API.
- **Логирование** — структурированные логи (JSON).
- **Мониторинг** — метрики (Prometheus), health-check.
- **Права доступа** — ACL на документ (сейчас только глобальные роли).
