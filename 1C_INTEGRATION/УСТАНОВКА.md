## Требования

### Системные требования

- **1С:Предприятие 8.3** версия 8.3.10 или выше
- **Python 3.8+** для системы документооборота
- **SQLite** (или другая БД для СЭД)
- Доступ к сети между серверами 1С и СЭД

### Проверка версии 1С

1. Откройте 1С:Предприятие
2. Меню "Справка" → "О программе"
3. Убедитесь, что версия платформы не ниже 8.3.10

## Подготовка системы документооборота

### Шаг 1: Запуск API документооборота

```bash
cd DIGITAL_DOCUMENTS_MVP/backend

# Создание виртуального окружения
python3 -m venv .venv
source .venv/bin/activate  # Linux/Mac
# или
.venv\Scripts\activate  # Windows

# Установка зависимостей
pip install -r requirements.txt

# Инициализация БД
python manage.py init-db

# Создание пользователя для интеграции с 1С
python manage.py create-user --username 1c_integration --password SecurePassword123 --role admin
```

### Шаг 2: Запуск сервера

```bash
uvicorn lexima_dms.api.main:app --host 0.0.0.0 --port 8080
```

Проверьте доступность API:
```bash
curl http://localhost:8080/docs
```

### Шаг 3: Настройка для продуктивной среды

Для продуктивного использования рекомендуется:

1. **Настроить HTTPS**: Используйте nginx или другой reverse proxy
2. **Настроить систему управления процессами**: systemd, supervisor
3. **Настроить логирование**: централизованный сбор логов

Пример конфигурации nginx:

```nginx
server {
    listen 443 ssl;
    server_name dms.example.com;

    ssl_certificate /path/to/cert.pem;
    ssl_certificate_key /path/to/key.pem;

    location / {
        proxy_pass http://localhost:8080;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }
}
```

## Установка в 1С

### Метод 1: Загрузка общего модуля (рекомендуется)

1. **Откройте конфигуратор 1С**
   - Запустите 1С:Предприятие в режиме конфигуратора
   - Откройте вашу конфигурацию

2. **Создайте общий модуль**
   - В дереве конфигурации: Общие → Общие модули
   - Нажмите правой кнопкой → Добавить
   - Имя: `МодульИнтеграцииAPI`
   - Установите флаги:
     - ✓ Сервер
     - ✓ Внешнее соединение
     - ✓ Привилегированный (опционально)

3. **Скопируйте код модуля**
   - Откройте файл `МодульИнтеграцииAPI.bsl`
   - Скопируйте весь код
   - Вставьте в созданный общий модуль

4. **Сохраните изменения**
   - Нажмите Ctrl+S
   - Обновите конфигурацию БД (F7)

### Метод 2: Использование внешней обработки

1. **Скомпилируйте внешнюю обработку** (если есть .epf файл)
   - Файл → Открыть
   - Выберите `ОбработкаИнтеграцияДМС.epf`

2. **Или создайте внешнюю обработку вручную**
   - В конфигураторе: создайте новую внешнюю обработку
   - Имя: `ИнтеграцияДМС`
   - Скопируйте код из файла `ОбработкаИнтеграцияДМС.bsl`
   - Сохраните как .epf файл

3. **Регистрация внешней обработки**
   - В режиме 1С:Предприятие
   - Справочник "Дополнительные отчеты и обработки"
   - Добавьте новую запись
   - Загрузите .epf файл

### Метод 3: Установка HTTP-сервиса (для приема веб-хуков)

1. **Создайте HTTP-сервис**
   - В конфигураторе: HTTP-сервисы
   - Нажмите правой кнопкой → Добавить
   - Имя: `ДокументооборотAPI`
   - URL: `dms`

2. **Добавьте методы HTTP-сервиса**
   - Создайте шаблоны URL:
     - `webhook/document-approved` → метод `POST`
     - `webhook/document-rejected` → метод `POST`
     - `health` → метод `GET`

3. **Скопируйте код**
   - Откройте файл `HTTPСервисДокументооборот.bsl`
   - Скопируйте соответствующие функции в методы HTTP-сервиса

4. **Опубликуйте HTTP-сервис**
   - Администрирование → Публикация веб-сервисов
   - Включите HTTP-сервис `ДокументооборотAPI`

## Настройка

### Создание констант

1. **Откройте конфигуратор**
2. **Создайте константы**:
   
   ```
   Константы:
   ├─ АдресСерверДМС (Строка, длина 255)
   ├─ ЛогинДМС (Строка, длина 50)
   └─ ПарольДМС (Строка, длина 50, Пароль)
   ```

3. **Создайте форму настроек** (опционально)
   
   Или установите значения через код:
   
   ```1c
   Константы.АдресСерверДМС.Установить("http://localhost:8080");
   Константы.ЛогинДМС.Установить("1c_integration");
   Константы.ПарольДМС.Установить("SecurePassword123");
   ```

### Добавление реквизитов к документам

Для отслеживания статуса согласования добавьте к документам:

```
Реквизиты документа (например, СчетНаОплату):
├─ ИдентификаторВСЭД (Число, 10, 0)
└─ СтатусСогласования (ПеречислениеСсылка.СтатусыСогласования)

Перечисление СтатусыСогласования:
├─ НеОтправлен
├─ НаСогласовании
├─ Согласован
└─ Отклонен
```

### Настройка прав доступа

1. **Права на внешние обработки**
   - Администрирование → Права пользователей
   - Добавьте право "Использование внешних обработок"

2. **Права на HTTP-сервисы**
   - Настройте аутентификацию для HTTP-сервисов
   - Рекомендуется использовать базовую аутентификацию или токены

## Проверка работоспособности

### Тест 1: Проверка подключения к API

```1c
Процедура ТестПодключения()
    
    Обработка = ВнешниеОбработки.Создать("ИнтеграцияДМС");
    Обработка.УстановитьПараметрыПодключения(
        "http://localhost:8080",
        "1c_integration",
        "SecurePassword123"
    );
    
    Результат = Обработка.ТестироватьПодключение();
    
    Если Результат.Успех Тогда
        Сообщить("✓ Подключение работает");
    Иначе
        Сообщить("✗ Ошибка: " + Результат.Сообщение);
    КонецЕсли;
    
КонецПроцедуры
```

### Тест 2: Отправка тестового документа

```1c
Процедура ТестОтправкиДокумента()
    
    Обработка = ВнешниеОбработки.Создать("ИнтеграцияДМС");
    Обработка.УстановитьПараметрыПодключения(
        Константы.АдресСерверДМС.Получить(),
        Константы.ЛогинДМС.Получить(),
        Константы.ПарольДМС.Получить()
    );
    
    // Найдите любой документ для теста
    Запрос = Новый Запрос;
    Запрос.Текст = "ВЫБРАТЬ ПЕРВЫЕ 1 Ссылка ИЗ Документ.СчетНаОплату";
    Документ = Запрос.Выполнить().Выбрать();
    
    Если Документ.Следующий() Тогда
        
        МассивСогласующих = Новый Массив;
        МассивСогласующих.Добавить("1c_integration");
        
        Результат = Обработка.ОтправитьДокументВСЭД(
            Документ.Ссылка,
            "Тестовый документ",
            "test",
            МассивСогласующих,
            Ложь
        );
        
        Если Результат.Успех Тогда
            Сообщить("✓ Документ отправлен. ID: " + Результат.ИдентификаторДокумента);
        Иначе
            Сообщить("✗ Ошибка: " + Результат.ТекстОшибки);
        КонецЕсли;
        
    Иначе
        
        Сообщить("Нет документов для теста");
        
    КонецЕсли;
    
КонецПроцедуры
```

## Решение проблем

### Проблема: Ошибка "Не удалось получить токен авторизации"

**Решение:**
1. Проверьте правильность логина и пароля
2. Убедитесь, что API документооборота доступен
3. Проверьте логи API (может быть проблема с аутентификацией)

```bash
# Проверка доступности API
curl -X POST http://localhost:8080/api/auth/token \
  -H "Content-Type: application/x-www-form-urlencoded" \
  -d "username=1c_integration&password=SecurePassword123"
```

### Проблема: Ошибка сертификата SSL

**Решение:**
Если используете самоподписанный сертификат, добавьте его в доверенные:

1. Экспортируйте сертификат сервера
2. В Windows: добавьте в хранилище сертификатов
3. В 1С может потребоваться отключить проверку сертификата (только для тестирования!)

### Проблема: Таймаут соединения

**Решение:**
1. Увеличьте таймаут в коде:
   ```1c
   Соединение = Новый HTTPСоединение(..., 60); // 60 секунд
   ```
2. Проверьте сетевую связность между серверами
3. Убедитесь, что файрвол не блокирует соединение

### Проблема: Ошибка "Метод не найден"

**Решение:**
1. Проверьте, что используется правильная версия API
2. Убедитесь, что все необходимые endpoint существуют в API
3. Проверьте правильность путей в коде

### Проблема: Документ не находится по GUID

**Решение:**
1. Убедитесь, что в метаданных документа добавлен GUID
2. Проверьте функцию `НайтиДокументПоГУИД()` в HTTP-сервисе
3. Добавьте нужные типы документов в массив поиска

## Безопасность

### Рекомендации по безопасности

1. **Используйте HTTPS** в продуктивной среде
2. **Не храните пароли в открытом виде** - используйте защищенное хранилище
3. **Ограничьте доступ** к внешним обработкам
4. **Регулярно меняйте пароли** интеграционных пользователей
5. **Логируйте все операции** для аудита
6. **Настройте файрвол** для ограничения доступа к API
7. **Используйте сильные пароли** (минимум 12 символов)
