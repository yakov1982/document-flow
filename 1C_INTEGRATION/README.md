# Интеграция 1С:Предприятие 8.3 с системой документооборота

Этот модуль обеспечивает интеграцию 1С:Предприятие 8.3 с системой электронного документооборота (СЭД) DIGITAL DOCUMENTS MVP.

## Состав интеграции

1. **HTTPСервисДокументооборот** - HTTP-сервис для приема запросов от внешних систем
2. **ОбработкаИнтеграцияДМС** - внешняя обработка для работы с API документооборота
3. **МодульИнтеграцииAPI** - общий модуль с функциями интеграции

## Возможности

### Отправка документов из 1С в СЭД

- Выгрузка документов 1С (счета, договоры, акты и т.д.)
- Прикрепление печатных форм в формате PDF
- Создание маршрутов согласования
- Отслеживание статусов согласования

### Получение данных из СЭД в 1С

- Получение списка документов
- Загрузка согласованных документов
- Синхронизация статусов
- Журнал аудита действий

## Установка

### 1. Загрузка внешней обработки

1. Откройте 1С:Предприятие 8.3 в режиме Конфигуратора
2. Файл → Открыть → Выберите `ОбработкаИнтеграцияДМС.epf`
3. Или используйте файл в формате XML для загрузки через конфигуратор

### 2. Установка HTTP-сервиса

1. В конфигураторе откройте раздел "HTTP-сервисы"
2. Создайте новый HTTP-сервис "ДокументооборотAPI"
3. Скопируйте код из `HTTPСервисДокументооборот.bsl`
4. Опубликуйте сервис на веб-сервере

### 3. Настройка подключения

В обработке или константах укажите:
- URL API документооборота: `http://localhost:8080`
- Логин и пароль пользователя 1С в системе СЭД
- Таймаут соединения (по умолчанию 30 сек)

## Использование

### Отправка документа на согласование

```1c
// Создание документа в СЭД
Обработка = ВнешниеОбработки.Создать("ИнтеграцияДМС");
Обработка.АдресСервера = "http://localhost:8080";
Обработка.Логин = "admin";
Обработка.Пароль = "admin";

// Отправка документа
ДокументСсылка = Документы.СчетНаОплату.НайтиПоНомеру("00001");
РезультатОтправки = Обработка.ОтправитьДокументВСЭД(
    ДокументСсылка,
    "Счет на оплату №00001",
    "invoice",
    Новый Массив // массив согласующих
);

Если РезультатОтправки.Успех Тогда
    Сообщить("Документ отправлен в СЭД. ID: " + РезультатОтправки.ИдентификаторДокумента);
КонецЕсли;
```

### Получение статуса согласования

```1c
Обработка = ВнешниеОбработки.Создать("ИнтеграцияДМС");
Статус = Обработка.ПолучитьСтатусДокумента(ИдентификаторДокумента);

Если Статус = "approved" Тогда
    Сообщить("Документ согласован");
ИначеЕсли Статус = "rejected" Тогда
    Сообщить("Документ отклонен");
КонецЕсли;
```

### Загрузка согласованных документов

```1c
Обработка = ВнешниеОбработки.Создать("ИнтеграцияДМС");
МассивДокументов = Обработка.ПолучитьСписокДокументов("approved");

Для Каждого Документ Из МассивДокументов Цикл
    Сообщить("Документ: " + Документ.Заголовок + ", Номер: " + Документ.РегистрационныйНомер);
КонецЦикла;
```

## Требования

- 1С:Предприятие 8.3 (платформа 8.3.10 и выше)
- Доступ к HTTP/HTTPS
- Установленная и настроенная система DIGITAL DOCUMENTS MVP

## Безопасность

- Используйте HTTPS в продуктивной среде
- Храните учетные данные в защищенном хранилище 1С
- Настройте права доступа к внешним обработкам
- Включите логирование всех операций интеграции

## Поддержка

При возникновении проблем проверьте:
1. Доступность API документооборота
2. Правильность учетных данных
3. Журнал ошибок 1С
4. Логи API документооборота
