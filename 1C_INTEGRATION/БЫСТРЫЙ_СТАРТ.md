# Быстрый старт интеграции 1С:Предприятие 8.3 с СЭД

## 🚀 Начало работы за 5 минут

Этот документ поможет вам быстро настроить интеграцию между 1С:Предприятие 8.3 и системой электронного документооборота.

## Шаг 1: Запуск системы документооборота

```bash
cd DIGITAL_DOCUMENTS_MVP/backend

# Активация виртуального окружения
python3 -m venv .venv
source .venv/bin/activate

# Установка зависимостей
pip install -r requirements.txt

# Инициализация БД
python manage.py init-db

# Создание пользователя
python manage.py create-user --username admin --password admin --role admin

# Запуск сервера
uvicorn lexima_dms.api.main:app --reload --port 8080
```

**Проверка:** Откройте http://localhost:8080/docs - должен открыться Swagger UI

## Шаг 2: Установка модуля в 1С

### Вариант А: Через общий модуль (для типовых конфигураций)

1. Откройте конфигуратор 1С
2. Создайте общий модуль `МодульИнтеграцииAPI`
3. Скопируйте код из файла `МодульИнтеграцииAPI.bsl`
4. Установите флаги: Сервер ✓, Внешнее соединение ✓
5. Сохраните (Ctrl+S) и обновите конфигурацию БД (F7)

### Вариант Б: Через внешнюю обработку (универсальный)

1. В режиме Предприятия
2. Файл → Открыть → Выберите `ОбработкаИнтеграцияДМС.bsl`
3. Или зарегистрируйте как дополнительную обработку

## Шаг 3: Первый запуск

### Тест подключения

```1c
// Выполните в консоли запросов 1С
Обработка = ВнешниеОбработки.Создать("ИнтеграцияДМС");
Обработка.УстановитьПараметрыПодключения(
    "http://localhost:8080",
    "admin",
    "admin"
);

Результат = Обработка.ТестироватьПодключение();
Сообщить(Результат.Сообщение);
```

**Ожидаемый результат:** "Подключение установлено успешно"

### Отправка первого документа

```1c
// Найдите любой документ
Запрос = Новый Запрос;
Запрос.Текст = "ВЫБРАТЬ ПЕРВЫЕ 1 Ссылка ИЗ Документ.СчетНаОплату";
Выборка = Запрос.Выполнить().Выбрать();

Если Выборка.Следующий() Тогда
    
    Обработка = ВнешниеОбработки.Создать("ИнтеграцияДМС");
    Обработка.УстановитьПараметрыПодключения(
        "http://localhost:8080",
        "admin",
        "admin"
    );
    
    МассивСогласующих = Новый Массив;
    МассивСогласующих.Добавить("admin");
    
    Результат = Обработка.ОтправитьДокументВСЭД(
        Выборка.Ссылка,
        "Тестовый документ",
        "test",
        МассивСогласующих,
        Ложь
    );
    
    Если Результат.Успех Тогда
        Сообщить("✓ Документ отправлен! ID: " + Результат.ИдентификаторДокумента);
    Иначе
        Сообщить("✗ Ошибка: " + Результат.ТекстОшибки);
    КонецЕсли;
    
КонецЕсли;
```

### Типичные сценарии

#### Сценарий 1: Согласование счетов

```1c
// Отправить счет на согласование руководителю
Результат = Обработка.ОтправитьДокументВСЭД(
    СчетСсылка,
    "Счет №" + СчетСсылка.Номер,
    "invoice",
    ["director"],
    Истина  // С печатной формой
);
```

#### Сценарий 2: Проверка статуса

```1c
// Проверить, согласован ли документ
Статус = Обработка.ПолучитьСтатусДокумента(ИдентификаторДокумента);

Если Статус = "approved" Тогда
    // Документ согласован, можно провести
    ДокументОбъект.Записать(РежимЗаписиДокумента.Проведение);
КонецЕсли;
```

#### Сценарий 3: Мои задачи

```1c
// Получить список моих задач на согласование
МоиЗадачи = Обработка.ПолучитьМоиЗадачи();

Для Каждого Задача Из МоиЗадачи Цикл
    Сообщить("Задача: " + Задача.document.title);
КонецЦикла;
```

## Поддержка

### Проблемы с подключением?

```1c
// Проверьте доступность API
Соединение = Новый HTTPСоединение("localhost", 8080);
Запрос = Новый HTTPЗапрос("/docs");
Ответ = Соединение.Получить(Запрос);
Сообщить("Код ответа: " + Ответ.КодСостояния);
```

### Ошибка авторизации?

- Убедитесь, что пользователь создан в системе документооборота
- Проверьте правильность логина и пароля
- Проверьте журнал регистрации 1С

### Нужна помощь?

1. Проверьте журнал регистрации 1С
2. Проверьте логи API (в терминале где запущен uvicorn)
3. См. раздел "Решение проблем" в [УСТАНОВКА.md](./УСТАНОВКА.md)

## Безопасность
