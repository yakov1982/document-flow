# document-flow

Репозиторий содержит два проекта системы документооборота:

## Проекты

### 1. DIGITAL DOCUMENTS MVP (Python / FastAPI)
Минимально рабочая система документооборота: реестр документов, версии файлов, согласование, задачи, аудит.
- Подробнее: [`DIGITAL_DOCUMENTS_MVP/README.md`](DIGITAL_DOCUMENTS_MVP/README.md)

### 2. Документооборот — 1С:Предприятие 8.3
Полноценная конфигурация для платформы 1С:Предприятие 8.3 с аналогичной функциональностью: справочники, документы (входящие/исходящие/внутренние), маршруты согласования, журнал аудита, версионирование файлов, роли и права.
- Подробнее: [`1C_Enterprise_DocumentFlow/README.md`](1C_Enterprise_DocumentFlow/README.md)
