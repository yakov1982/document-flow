В этом репозитории лежит **DIGITAL DOCUMENTS MVP** — минимально рабочая система документооборота (реестр документов, версии файлов, согласование, задачи, аудит).

## Проекты

- **Система документооборота**: `DIGITAL_DOCUMENTS_MVP/README.md`
- **Интеграция с 1С:Предприятие 8.3**: `1C_INTEGRATION/README.md`

## Интеграция с 1С:Предприятие 8.3

Реализована полнофункциональная интеграция с 1С:Предприятие 8.3 для обмена документами и синхронизации процессов согласования.

### Возможности интеграции

- ✅ Отправка документов из 1С в систему документооборота
- ✅ Создание маршрутов согласования
- ✅ Согласование/отклонение документов
- ✅ Синхронизация статусов между системами
- ✅ Прикрепление печатных форм
- ✅ HTTP-сервис для приема веб-хуков от СЭД
- ✅ Журнал аудита всех операций
